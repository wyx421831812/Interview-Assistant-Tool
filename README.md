# 面伴 · AI 面试辅助工具

> 把简历和项目笔记，变成一套能「练、讲、查、复盘」的面试备战系统。

「面伴」是一个面向求职者的本地优先（Local-first）AI 面试助手。它围绕「项目经验」这一锚点，把静态的简历与面试笔记转化为动态的面试能力，帮助你在正式面试前完成项目深挖、技术追问、表达演练和复盘迭代。数据全部保存在本地浏览器，隐私安全，无需后端。

## 核心功能（六大模块）

| 模块 | 做什么 | 价值 |
|---|---|---|
| 简历解析与画像 | 导入简历，自动提取项目、技术栈、职责，生成面试画像 | 建立"已具备"的能力清单 |
| 笔记知识库 | 导入面试笔记，按项目/主题归类，支持语义检索 | 把零散笔记变成可调用话术 |
| 模拟面试 | AI 扮演面试官层层追问（项目深挖 / 技术追问 / STAR 话术） | 练表达、练临场 |
| 回答点评 | 多维度结构化评分 + 改进版回答示范 | 定位薄弱、给出示例 |
| 面试复盘 | 错题本、能力雷达图、进步追踪 | 针对性补强，越面越强 |
| 高频题预测 | 结合画像与目标岗位，生成押题清单 | 考前重点突破 |

## 技术方案

- **形态**：纯前端单页应用（Web App），本地运行、数据私有
- **前端**：HTML / CSS / Vanilla JS（无框架依赖，零构建，开箱即用）
- **数据存储**：浏览器 `localStorage` / `IndexedDB`，全部数据不上传
- **AI 能力**：用户自有大模型服务 API Key（兼容 OpenAI Chat Completions / Anthropic Messages 协议），Key 仅存本地
- **隐私**：所有数据与密钥仅保存在用户本地浏览器

## 快速开始

1. 克隆或下载本仓库。
2. 直接打开 `index.html`（或用任意静态服务器：`python3 -m http.server 8000`）。
3. 在「设置」中填入你的大模型 API Key 并选择模型。
4. 导入简历 → 添加面试笔记 → 开始「模拟面试」。

## 产品定位

- 偏场景：**项目深挖讲述**为主，兼顾技术追问与 STAR 结构化表达。
- 价值主张：让每次面试准备都有「练习 → 反馈 → 复盘 → 进步」的完整闭环。
